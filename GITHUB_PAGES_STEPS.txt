# Publish a public DemoBuddy URL using GitHub Pages

The current source is static (one HTML file plus no external dependencies), so it can be hosted as a static site.

1. Sign in to GitHub and create a new PUBLIC repository named `demobuddy`.
2. Upload `index.html` from this folder to the repository root; optionally also upload `demobuddy-cover.png` and `README.md`.
3. Open repository Settings → Pages.
4. Under Build and deployment, select “Deploy from a branch”.
5. Select branch `main` and folder `/(root)`, then Save.
6. Wait for GitHub Pages to publish and open the URL shown in the Pages section. It normally looks like `https://YOUR-USERNAME.github.io/demobuddy/`.
7. Open the published URL in a private browser window and test the sample flow before using it in the article.

Don't claim the public demo is live until the URL has loaded and the interaction has been checked.
