🛡️ Demo Rescue Arsenal

Don't panic when things break. Pick your scenario for an instant battle-tested fallback script.

💥 Live Demo Crashed (500 Error / Exception)
The app froze or spat out a red error stack during your live demonstration.
“It looks like our backend ran into an unexpected edge case. While I check the server logs, let me walk you through the architecture diagram and show the recorded workflow from our test suite.”
📡 WiFi or Network Connection Dropped
API requests are timing out or the stage network has locked up.
“The venue network appears to have disconnected our live API socket. I have local cached seed data and offline mocks ready right here to show the user experience seamlessly.”
🗄️ Database / Auth / Secret Key Glitch
Login token expired or database migration mismatch on production.
“Our auth provider token has expired on the stage IP. I am switching immediately to our pre-seeded guest demo profile so you can see the core value proposition.”
⚠️ UI Lag or Empty Screen
Rendering didn't update or state is stuck in loading spinner.
“The client state is waiting on a slow asynchronous batch. The key engineering decision we made here is graceful degradation—here is how the system recovers when retrying.”
